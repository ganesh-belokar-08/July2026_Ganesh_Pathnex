# Day 04 — More Packages, Key Pair, Service

## 🔹 Ansible — Install Multiple Packages

---
- name : Install Multiple Packages
  hosts : all
  become : yes


  tasks :
    - name : Install tools
    yum :
      name :
        - git
        - wget
      state : present 

## 🔹 Terraform — EC2 with Key Pair (c6i.8xlarge)

provider "aws"{
    region = "us-east-1"
}

resouce "aws_key_pair" "PathnexKey"{
    key_name = "PathnexKey"
    public_key = "ssh-rsa AAAA...."
}

resources "aws_instance" "PathnexEC2"{
    ami = "ami-oueisdfknlsdj433"
    instance_type = "c6i.8xlarge"
    key_name = aws_key_pair.PathnexKey.key_name

    tags={
        Name = "Pathnex-EC2"
    }
}


## 🔹 Kubernetes — Create ClusterIP Service
