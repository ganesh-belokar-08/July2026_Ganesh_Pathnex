# Day 05 — Handlers, User-Data, Resource Limits

## 🔹 Ansible — Handler to Restart Nginx

---
- name : Manage Nginx
  hosts : all
  become : yes

  tasks :
    - name : Update Config file
      copy :
         src : index.html
         dest : /usr/home/nignx/index.html
      notify : Restart Nginx

  handlers :
    - name : Restart Nginx
      service :
        name : Nginx
        state : restarted
